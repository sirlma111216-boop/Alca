# 화면 디자인

브릭픽의 화면은 **하나의 디자인 언어**로 그려져 있습니다.
색을 하나 고르거나 버튼을 하나 더 만들기 전에 이 문서를 먼저 보세요.

원본 규격: `DESIGN-together.ai.md` (Together AI 의 디자인 언어를 해석한 문서).
브릭픽에 맞게 옮긴 결과가 [`src/styles/tokens.css`](../src/styles/tokens.css) 입니다.
**수치를 바꾸려면 그 파일만 고칩니다.** 다른 스타일시트는 거기 있는 `--t-*` 만 씁니다.

---

## 1. 한 문장으로

> 짙은 남색 띠와 흰 띠가 번갈아 가고, 장식은 주황→자홍→연보라 그라디언트 하나뿐이며,
> 제목은 문장형 산세, 라벨은 전부 대문자 고정폭이다.

---

## 2. 면 — 짙은 띠와 밝은 띠

이 디자인에는 **중간 회색 면이 없습니다.** 면은 둘 중 하나입니다.

| 면 | 값 | 브릭픽에서 어디 |
|---|---|---|
| 짙은 면 | `#010120` | 머리띠 · 큰 머리말 · **게임판** · 발표자 발표 · 학생 경기 화면 |
| 밝은 면 | `#ffffff` | 설정 화면 · 결과 표 · 꼬리말 · 학생 입력 화면 |

연한 면은 `#ebebeb` 하나뿐이고, **표의 머리줄과 단계 표시 레일에만** 씁니다.

### 선은 역할이 셋입니다

원본 규격은 선을 `#ebebeb` 하나로 둡니다. 그런데 그 값은 흰 면에서 **1.19:1** 이라
사실상 안 보입니다 — 카드도 입력칸도 테두리가 없는 것처럼 보입니다.
그래서 역할별로 셋으로 갈랐습니다.

| 역할 | 밝은 면 | 짙은 면 | 대비 | 어디에 |
|---|---|---|---|---|
| **면** | `#ebebeb` | — | 필요 없음 | 표 머리줄·단계 표시 레일처럼 **칠하는** 자리 |
| **구분선** | `#b0b0b0` | `#454563` | 2.2:1 | 이미 윤곽이 잡힌 부품 **안쪽**을 가르는 줄 (표의 줄, 목록의 줄) |
| **윤곽** | `#8c8c8c` | `#5e5e80` | 3.3:1 | 부품의 **경계** (카드·입력칸·버튼·선택칸) |

윤곽이 3:1 이어야 하는 건 WCAG 1.4.11 입니다 — "부품을 식별하는 데 필요한 시각 정보".
카드가 흰 면 위에 흰 면으로 있고 그림자도 없으면, **테두리가 유일한 경계**이므로 여기 해당합니다.

고를 때는 값이 아니라 "이게 무슨 역할인가" 로 고르면 됩니다.

깊이는 **1px 선과 면의 명암**이 만듭니다.
밝은 면의 카드에 그림자를 깔지 마세요. 그림자가 허용되는 곳은 **떠 있는 발사 버튼 하나**뿐입니다
(`.bp-fire` — 완전한 원 모양도 여기서만 씁니다).

```
머리띠(짙음) → 단계·설정(밝음) → 게임판(짙음) → 결과 표(밝음) → 발표자(짙음) → 꼬리말(밝음)
```

띠는 화면 끝에서 끝까지 색을 칠하고, 안의 내용만 1280px 로 모읍니다.
`.bp-band` 가 그 일을 하므로 감싸는 `<div>` 를 더 두지 않아도 됩니다.

## 3. 색 — 다섯 번째 강조색을 만들지 않는다

장식에 쓸 수 있는 색은 **넷**뿐입니다.

| 이름 | 값 | 쓰는 곳 |
|---|---|---|
| 주황 | `#fc4c02` | 그라디언트의 첫 다리 · 경고 · 되돌릴 수 없는 버튼 |
| 자홍 | `#ef2cc1` | 그라디언트의 둘째 다리 |
| 연보라 | `#bdbbff` | 그라디언트의 셋째 다리 · 패들 |
| 민트 | `#c8f6f9` | 수치 타일 · 짙은 면의 보조 버튼 · 공의 잔상 |

앞의 셋은 **그라디언트 하나의 덩어리**입니다. 한 색만 떼어 큰 면을 칠하거나,
순서를 바꾸거나, 네 번째 색을 더하지 마세요. 아이콘 크기로 줄이지도 않습니다.

기본 버튼은 **검정 `#000000` 사각형**(모서리 4px) 하나입니다.
보이는 화면마다 검정 버튼은 하나면 충분합니다.
민트·흰색 버튼은 **짙은 면에서만** 쓰는 보조 버튼입니다.

### 게임판의 색

벽돌 벽이 이 그라디언트를 보여 주는 자리입니다 — 장식을 따로 만들지 않았습니다.
위에서 아래로 은백 → 주황 → 자홍 → 연보라 → 민트이고, 가운데 셋이 그라디언트 순서 그대로입니다.
정확한 값은 [game-rules.md 의 점수표](./game-rules.md#2-점수표)와
[`src/core/config.ts`](../src/core/config.ts) 에 있습니다.

### 원본 규격에서 일부러 벗어난 곳

전부 **읽히는지**의 문제입니다. 교실에서 실제로 봐야 하는 화면이라 그냥 두지 않았습니다.
원본 규격은 라틴 글자를 쓰는 마케팅 사이트를 기준으로 쓰였고, 이 화면은 한글을 쓰는
수업 도구라서 어긋나는 지점이 생깁니다.

| 원본 | 바꾼 값 | 이유 |
|---|---|---|
| 보조 글씨 `#959494` | **`#5a5a5a`** | 흰 면에서 2.9:1. WCAG AA 기준은 4.5:1 입니다. 라벨까지 이 색이라 그대로 두면 안 읽힙니다. 바꾼 값은 흰 면 6.9:1, 연한 면 5.5:1. |
| 선 `#ebebeb` 하나 | **면 / 구분선 / 윤곽 셋으로** | 위의 "선은 역할이 셋입니다" 참고. 원본 값은 흰 면에서 1.19:1 이라 박스가 안 보입니다. |
| 라벨 11px / 10px | **13px / 12px** | 원본 크기는 **라틴 대문자** 기준입니다. 이 화면의 라벨은 거의 다 한글이고, 한글은 같은 px 에서 획이 훨씬 빽빽해 11px 이면 교실에서 읽히지 않습니다. |
| 경고·오류 **글자**를 주황으로 | **글자는 검정, 주황은 테두리·막대로** | 주황 `#fc4c02` 은 흰 면에서 3.4:1 이라 글자로 못 씁니다. 테두리는 글자가 아니므로 3:1 만 넘으면 되고(3.4:1), 원본 규격도 "검증 신호는 기본 검정이나 브랜드 그라디언트로" 라고 적고 있습니다. |
| 누를 수 없는 버튼 `opacity: 0.4` | **꺼진 면을 따로 칠하기** | 검정 버튼이 흐려지면 `#999` 면에 흰 글자가 되어 2.85:1 로 떨어집니다. 무슨 버튼인지 읽을 수가 없습니다. |

주황은 **짙은 면 위에서는** 5.3:1 이라 글자로 써도 됩니다 — 게임판의 남은 시간 경고가 그 예입니다.

### 성공·오류 색이 없다

이 디자인에는 성공 초록·오류 빨강이 **없습니다.** 그래서 상태는 이렇게 알립니다.

- **글자로** — "끊김" · "제외" · "완료" · "오류" 라는 말을 항상 붙인다
- **기호로** — ● / ○ · ✓ / ⚠ · 캡슐의 `E`/`C`/`M`/`S`/`L`/`B`/`+`
- **면을 뒤집어서** — 고른 것·뽑힌 사람은 검정(또는 흰색) 면으로 반전한다
- **색은 거들기만** — 급한 것에만 주황을 얹는다

원래 프로젝트 규칙("색만으로 상태를 구분하지 않는다")과 같은 방향입니다.

## 4. 글자 — 두 얼굴

| 쓰임 | 글꼴 | 굵기 | 자간 |
|---|---|---|---|
| 제목 · 본문 · 사람 이름 | Inter(라틴) + 한국어 글꼴 | 400 / 500 | **음수** |
| 라벨 · 버튼 글씨 · 표 머리 | JetBrains Mono, 대문자 | 500 | **양수** |

- **제목은 언제나 문장형.** 대문자는 전부 고정폭의 몫입니다.
- **고정폭이 문단을 나르지 않습니다.** 라벨 전용입니다.
  숫자여도 문장이면(예: "42초 만에 클리어") 본문 글꼴을 씁니다.
- 음수 자간은 산세만, 양수 자간은 고정폭만. **뒤집으면 틀린 것입니다.**
- 굵기 700 이상을 쓰지 않습니다.

Inter 와 JetBrains Mono 에는 **한글이 없습니다.** 라틴 글자와 숫자만 이 둘이 맡고
한글은 뒤따르는 한국어 글꼴(Pretendard → Noto Sans KR → 맑은 고딕)이 맡습니다 — 의도한 조합입니다.

글꼴은 `@fontsource` 로 **자체 호스팅**합니다(`src/standalone/main.tsx` 가 불러옴).
외부 CDN 으로 나가는 요청이 없으므로 교실 네트워크가 막혀 있어도 화면이 뜹니다.
라이브러리 빌드(`dist-lib/`)에는 글꼴 파일이 들어가지 않습니다 — 수업 앱 안에서는
호스트의 시스템 글꼴로 그려집니다.

### 교실에서 읽혀야 하는 글자

디자인 문서의 크기는 **노트북 앞에 앉은 사람 기준**입니다.
교실 맨 뒤에서 읽어야 하는 것만 그 자리에서 따로 크게 잡습니다.

- 수업 코드 (`.bp-live-code`) — 최대 168px
- 남은 시간 (`.bp-timer__value`), 시작 카운트다운 (`.bp-count`)
- 발표자 이름 (`.bp-winner__name`, `.bp-live-winner__name`) — `--bp-fs-hero`

## 5. 모양과 여백

- 모서리는 **4px** 하나입니다. 3.25px 는 단계 표시 칸에만, 완전한 원은 발사 버튼에만.
- 여백은 4px 배수. 구역과 구역 사이는 **80px**(좁은 화면 48px).
- 가로 최대 1280px, 좌우 여백 32px(좁은 화면 16px).
- 손가락으로 누르는 버튼은 **44px** 아래로 내려가지 않습니다.

## 6. 스타일시트가 나뉜 이유

| 파일 | 범위 | 주의 |
|---|---|---|
| `tokens.css` | `:root` 토큰 + `.t-*` 도우미 | 단독 사이트에서만 불러온다 |
| `standalone.css` | 설정·결과 화면 전체 | 이 파일이 `tokens.css` 를 불러온다 |
| `brickpick.css` | **게임 화면** | npm 패키지로 나간다 — `:root`·`body`·`*` 를 쓰지 않는다. 토큰을 `.bp-root` 안에 다시 적는다 |
| `live.css` | 교사 실시간 화면 | |
| `student.css` | 학생 폰 화면 | |
| `practice.css` | 혼자 연습하기 | |

`brickpick.css` 만 규칙이 다릅니다. 이 CSS 는 **수업 앱 안으로 그대로 들어가므로**
전역 선택자를 쓰면 호스트의 화면을 망가뜨립니다. 그래서 `tokens.css` 를 불러오지 않고
필요한 값을 `.bp-root` 안에 직접 선언합니다.

## 7. 새로 무언가를 만들 때의 점검표

- [ ] 새 색을 만들지 않았다 (강조 넷 + 검정 + 흰색 + 면/선 토큰 안에서 해결)
- [ ] 테두리를 `--t-border`(윤곽) 와 `--t-line`(구분선) 중 **역할에 맞게** 골랐다
      — `--t-hairline` 은 **칠하는 면** 전용이다. 테두리에 쓰면 안 보인다
- [ ] 라벨이 13px 아래로 내려가지 않았다 (한글이 안 읽힌다)
- [ ] 라벨과 버튼 글씨는 대문자 고정폭, 제목은 문장형 산세
- [ ] 밝은 면의 카드에 그림자가 없다
- [ ] 모서리가 4px 이다
- [ ] 상태를 색으로만 알리지 않는다 — 글자나 기호가 함께 있다
- [ ] 짙은 면에 얹은 버튼이 검정 글씨로 안 보이게 되지 않았다
      (짙은 면 목록은 `standalone.css` 의 "짙은 면 위에서는…" 주석 옆에 모아 두었다)
- [ ] 375px 폭에서 가로 스크롤이 없다
- [ ] 닉네임을 `textContent` / React `{}` 로 출력한다 — `innerHTML` 금지
